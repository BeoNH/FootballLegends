# Architecture Decision Records (ADR)

Ghi quyết định kiến trúc quan trọng — **tại sao** chọn pattern A thay vì B.

## Khi nào tạo ADR

- Chọn pattern event vs direct reference
- Cấu trúc module mới
- Save/load format, network protocol
- Trade-off performance vs maintainability

## Quy trình

1. Copy `_template.md` → `NNNN-slug-ngắn.md` (số tăng dần: 0001, 0002…)
2. Điền khi `/new-feature` hoặc refactor lớn
3. Link từ spec Fxxx và `03-ARCHITECTURE.md` nếu liên quan
